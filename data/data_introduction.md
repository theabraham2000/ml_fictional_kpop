# K-pop Group Synthetic Dataset

## Overview

This dataset contains **100 fictional K-pop groups** generated from a simulated data-generation process. Each group is assigned to a fictional parent company, given a gender category, debut year, demographic characteristics, commercial performance, fandom characteristics, organizational characteristics, and other simulated attributes. The dataset is designed for learning data analysis, statistics, machine learning, anomaly detection, and exploratory data analysis.

The data is **synthetic**. The companies, groups, measurements, and relationships were generated by code and should not be interpreted as real-world information about actual K-pop groups.

## Dataset Size

- Number of groups: **100**
- Number of public variables: **32**
- Number of parent companies: **7**
- Boy groups: **48**
- Girl groups: **52**
- Intentionally generated anomalies: approximately **5**

### What these company parameters mean

- **Tier:** A simulated company status/resource category. Higher values generally represent greater company resources.

- **Resource base:** Baseline level of resources available to groups from the company. Range in this dataset: **0.30–0.90**.

- **Consistency bias:** Baseline tendency toward maintaining a consistent concept. Range: **0.20–0.80**.

- **Debut share:** Relative probability that a generated group comes from that company. The values are normalized before sampling, so they represent relative weights rather than exact percentages.

## Why Are Some Variables Logged?

Several variables are stored using `log1p(x)`, which means `log(1 + x)`. These include:

- `streaming_log`
- `mv_views_log`
- `album_sales_log`
- `fan_cafe_log`
- `fan_labor_log`
- `chart_peak_inv_log`

These variables represent quantities that can have very large differences between groups. For example, one group might have thousands of streams while another has millions. A logarithmic transformation compresses these large values and makes the distribution easier to analyze.

For example, if the original value is 1,000,000, the stored value is approximately `log(1 + 1,000,000) = 13.82`. Therefore, a column ending in `_log` should not be interpreted as the original measurement itself.

## Hidden Answer Key

The file `kpop_groups_answer_key.csv` contains information that is intentionally hidden from students. It records the ground truth used when generating the dataset.

It contains:

- `firm_code` — internal company code.
- `true_archetype` — the hidden archetype assigned to the group.
- `is_anomaly` — whether the row was intentionally modified.
- `latent_commercial` — hidden commercial strength.
- `latent_digital` — hidden digital momentum.
- `latent_fandom` — hidden fandom strength.
- `latent_instability` — hidden instability.
- `latent_prestige` — hidden prestige.

## Data Generation Process

1. A random number generator is initialized using the configured seed.
2. Each group is assigned a parent company.
3. Each company influences which hidden archetypes are more likely.
4. A hidden archetype generates five latent characteristics.
5. Gender is generated using company-specific probabilities.
6. A unique fictional group name is assigned.
7. Debut year and years active are generated.
8. The latent characteristics and company characteristics are used to generate the observable variables.
9. Approximately 5% of groups receive deliberately unusual modifications.
10. The observable variables are written to the public CSV.
11. The hidden ground truth is written to the answer-key CSV.

## Suggested Student Workflow

Students should normally begin with `kpop_groups.csv` and use this document to understand the structure of the dataset. They should not use the answer key when attempting to discover patterns, classify groups, or detect anomalies. The answer key can be used afterward to evaluate their findings against the known ground truth.
